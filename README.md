# reiting-test

Барномаи Android барои омодагӣ ба **тести рейтингӣ** (донишҷӯи курси аввал, Тоҷикистон).
Пурра **офлайн** кор мекунад: ҳисоб, сервер ва интернет лозим нест.

- Забон: Kotlin · UI: Jetpack Compose + Material 3 · Gradle Kotlin DSL
- Модули бумӣ: C++ (NDK + CMake) — омезиши детерминистии саволҳо ва вариантҳо
- `applicationId`: `tj.reitingtest` · минималӣ: Android 8.0 (API 26)
- 8 фан × 50 савол = **400 савол**; тавсифи интерфейс: тоҷикӣ (асосӣ), русӣ, англисӣ
- Пешрафт, таърихи тестҳо, хатоҳо ва танзимот дар худи дастгоҳ (DataStore) нигоҳ дошта мешаванд

## ⚠️ Ҳолати воқеии лоиҳа

- Лоиҳа дар муҳити бе Android SDK ва бе интернет навишта шуд, бинобар ин **APK дар ҳамон ҷо сохта нашудааст** ва тестҳои Kotlin иҷро нашудаанд.
- Санҷиши JSON (`tools/validate_questions.py`) воқеан иҷро шуд: 8 файл, 400 савол, хато нест.
- Аввалин сохтани воқеӣ дар GitHub Actions мешавад. Агар хато барояд, матни хаторо аз лог гирифта, ислоҳ кунед.
- `gradle-wrapper.jar` дар архив нест (файли бинарӣ). Workflow Gradle 8.9-ро худаш насб мекунад (`gradle/actions/setup-gradle`), бинобар ин `gradlew` лозим нест. Барои Android Studio як бор `gradle wrapper` иҷро кунед.
- Технологияҳои иловагӣ (MediaCodec, Media3 Transformer, OpenGL ES, Vulkan) **дохил карда нашудаанд**: барои барномаи тест ба онҳо эҳтиёҷ нест ва мо онҳоро танҳо барои «номи технология» илова намекунем.

## Чӣ тавр савол илова / таҳрир / нест кунем (Acode)

Файлҳо дар `app/src/main/assets/questions/` ҷойгиранд:

| Фан | Файл | Префикси ID |
|---|---|---|
| Таърихи муосири Тоҷикистон | `history_tajikistan.json` | `history_` |
| Географияи иқтисодӣ ва демография | `economic_geography_demography.json` | `geo_` |
| Забони хориҷӣ | `foreign_language.json` | `english_` |
| Экология | `ecology.json` | `ecology_` |
| Ҳуқуқ | `law.json` | `law_` |
| Математикаи олӣ | `higher_mathematics.json` | `math_` |
| Сиёсатшиносӣ | `political_science.json` | `politics_` |
| Забони русӣ | `russian_language.json` | `russian_` |

Ҳар файл — массиви JSON. Намунаи як савол:

```json
{
  "id": "ecology_051",
  "subjectId": "ecology",
  "question": "Матни савол",
  "options": { "A": "Вариант 1", "B": "Вариант 2", "C": "Вариант 3", "D": "Вариант 4" },
  "correctAnswer": "B",
  "explanation": "Шарҳи кӯтоҳи ҷавоби дуруст"
}
```

Қоидаҳо:

1. **Илова**: объекти нав пас аз охирин объект гузоред, байни объектҳо вергул (`,`) лозим аст, пас аз охирин не.
2. `id` бояд дар **ҳамаи** файлҳо ягона бошад (масалан `ecology_051`).
3. `subjectId` бояд бо номи файл (бе `.json`) баробар бошад.
4. `options` маҳз чор калид дорад: `A`, `B`, `C`, `D`; матнҳо гуногун ва холӣ набошанд.
5. `correctAnswer` — маҳз як ҳарфи `A`, `B`, `C` ё `D`. Ҷавоби дуруст аз вариантҳо ҷудо нигоҳ дошта мешавад; ҳангоми тест вариантҳо омехта мешаванд ва дурустӣ аз рӯи калид санҷида мешавад, на аз рӯи ҷой.
6. **Нест кардан**: объекти пурраро (аз `{` то `}`) ва вергули лозимаро хориҷ кунед.
7. Ҳар фан камаш 50 савол дошта бошад (тест инро месанҷад).

Барои баъзе саволҳои хатодор барнома садамa намекунад: онҳо гузаронида мешаванд ва дар **Танзимот → Санҷиши файлҳои савол** сабаб навишта мешавад. Файли вайрон тамоман бор нашавад, фани он «Файл бор нашуд» нишон медиҳад.

## Санҷиши JSON

Дар Termux (Python лозим):

```bash
pkg install python
python3 tools/validate_questions.py
```

Скрипт шумораи саволҳо, ID-ҳои такрорӣ, калидҳои нодуруст, майдонҳои намерасида ва JSON-и вайронро нишон медиҳад. Дар GitHub Actions ин санҷиш худаш пеш аз сохтан иҷро мешавад.

## Сохтани APK тавассути GitHub Actions (аз телефон)

1. Дар GitHub (браузер ё барномаи GitHub) репозиторийи нав созед, масалан `reiting-test`.
2. Архиви ZIP-ро дар телефон кушоед (ё дар Termux: `unzip reiting-test.zip`) ва **мундариҷаи** папкаи `reiting-test` (на худи папка)-ро ба репозиторий бор кунед. Папкаи `.github` бояд дар реша бошад.
   - Бо Termux: `git init && git add . && git commit -m "init" && git branch -M main && git remote add origin <URL> && git push -u origin main`
3. Шохаи асосӣ бояд `main` ном дошта бошад.
4. Ба **Actions** равед → workflow-и **Android CI**. Он бо push худаш оғоз мешавад; ё **Run workflow** (workflow_dispatch) -ро пахш кунед.
5. Пас аз анҷом (~10–20 дақиқа) дар поёни саҳифаи иҷро, дар бахши **Artifacts**, `reiting-test-debug-apk`-ро зеркашӣ кунед.
6. ZIP-ро кушоед, `app-debug.apk`-ро насб кунед (иҷозати «насб аз манбаи номаълум» лозим аст).

Агар қадам сурх шуд: қадами сурхро кушоед, хати охирини хатогиро нусхабардорӣ кунед ва ислоҳ намоед. Гузориши тестҳо дар artifact-и `test-reports` аст.

### Release APK бо имзо (ихтиёрӣ)

Калиди хусусиро **ҳаргиз** ба репозиторий накашед. Он ба GitHub Secrets илова мешавад:

1. Калид созед (Termux): `keytool -genkeypair -v -keystore release.jks -alias reiting -keyalg RSA -keysize 2048 -validity 10000`
2. Base64: `base64 -w0 release.jks` (натиҷаро нусхабардорӣ кунед).
3. Дар репозиторий: **Settings → Secrets and variables → Actions → New repository secret**, чор секрет илова кунед:
   - `KEYSTORE_BASE64` — натиҷаи base64
   - `KEYSTORE_PASSWORD` — гузарвожаи keystore
   - `KEY_ALIAS` — `reiting` (ё номи худатон)
   - `KEY_PASSWORD` — гузарвожаи калид
4. Workflow-ро аз нав иҷро кунед: артефакти `reiting-test-release-apk` низ пайдо мешавад. Бе `KEYSTORE_BASE64` қадами release танҳо гузаронида мешавад.

## Тестҳо

Бо `gradle testDebugUnitTest` (дар CI худаш иҷро мешавад):

- `QuestionBankTest` — 8 фан, ҳар кадом ≥ 50 савол, ҳамагӣ 400, ID-ҳои ягона, чор вариант ва як калиди дуруст, ҷавоби дуруст на ҳамеша дар як ҷой, матни такрорӣ нест
- `QuestionParserTest` — JSON-и вайрон, майдони намерасида, ID-и такрорӣ, `correctAnswer`-и нодуруст
- `QuizEngineTest` — ҳисоб, як маротиба ҷавоб додан, омехтани вариантҳо дурустиро тағйир намедиҳад, омезиши детерминистӣ
- `HistoryCodecTest` — захиракунии таърих ва беҳтарин натиҷа
- `androidTest/AssetsInstrumentedTest` — саволҳои дохили APK-ро дар дастгоҳ месанҷад (`gradle connectedDebugAndroidTest`, эмулятор лозим)

## Модули C++

`app/src/main/cpp/native_engine.cpp` омезиши Fisher–Yates (xorshift64*)-ро иҷро мекунад: тартиби саволҳо ва вариантҳо. Агар китобхона бор нашавад, ҳамон алгоритм дар Kotlin (`KotlinShuffle`) кор мекунад, бинобар ин барнома ҳамеша оғоз мешавад. Модул кӯчак аст ва барои «ном» илова нашудааст: ҳар ду татбиқ натиҷаи якхела медиҳанд.

## Нақшаи кор бо барнома

Асосӣ → фанро интихоб кунед (корт бо шумораи савол ва пешрафт) → 10 / 20 / 50 ё ҳамаи саволҳо → як савол, чор тугмаи калон; ҷавоби дуруст сабз, нодуруст сурх (ҷавоби дурусти сабз ҳам нишон дода мешавад) ва шарҳ → **Саволи навбатӣ** → рақами `7/20` → натиҷа (холҳо, фоиз, дуруст/нодуруст) → **Дида баромадани хатоҳо** ё **Аз нав супоридан** (саволҳо ва вариантҳо аз нав омехта мешаванд). Дар саҳифаи асосӣ тугмаи «Такрори хатоҳо» хатоҳои захирашударо аз ҳамаи фанҳо ҷамъ мекунад.
